## 4. 当前入口调用链

当前旧版设备开发中心的入口关系为：

```text
home-view.js
  onOpenDevicePlatform
        ↓
app.js
  onOpenDevicePlatform: () => P(true)
        ↓
app.js
  lazy(() => import("./device-platform-center.jsx"))
        ↓
旧设备开发中心
```

关键位置：

- `home-view.js:2641`：接收 `onOpenDevicePlatform`；
- `app.js:1617`：把页面按钮连接到打开状态；
- `app.js:1477`：懒加载旧设备开发中心。

入口调用链集中，后续可增加一个唯一适配层，无需修改旧版组件内部实现。

## 5. 新版隔离方案

N1 开始后采用以下边界：

```text
apps/web/src/app/device-platform-center.jsx
  旧版冻结，不改写

apps/web/src/styles/device-platform.css
  旧版冻结，不改写

apps/web/src/app/device-development-center/
  新版独立组件目录

apps/web/src/styles/device-development-center.css
  新版独立样式

apps/web/src/app/app.js + home-view.js
  旧版与新版分别懒加载、分别由可见入口打开
```

N0 最初记录的单入口适配方案已在 2026-10-01 按用户要求调整为双入口并行方案。入口层只负责：

1. 原“开发中心”始终打开旧版，“新版中心”始终打开新版；
2. 把 `open`、`onClose` 等稳定参数传给目标实现；
3. 不保存业务数据；
4. 不复制旧版逻辑；
5. 在新版出现加载错误时允许回退旧版。

N10 最终验收通过并获得用户明确授权前：

- 原“开发中心”入口保持可见并指向旧版；
- 新版通过旁边的独立可见入口挂载；
- 不删除旧入口，不迁移用户数据。

N1 验收通过且用户明确确认后：

- 正式入口切换到新版；
- 旧版入口仅从界面隐藏；
- 保留开发/回退开关；
- 使用同一份向后兼容数据。
