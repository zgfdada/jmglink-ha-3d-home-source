# 模型加载与预览资源生命周期

适用范围：.37 后本地开发版，2026-11-01；尚未发布新的 HAOS 版本。

## 名额与队列

原来共享最多六个预览，现改为最多两个 WebGL 预览名额，其中后台静态缩略图同时最多一个。另一名额可供交互预览；有两个交互预览时，后台任务等待。等待队列优先交互任务，但不会强行中断正在运行的解码。

模型文件下载／读取与 GLTF 解码另有一个全局串行队列，主页上传模型和开发中心共同使用，最多一个活动任务。预览名额包含初始化和等待文件加载的阶段，不等于每个名额都在渲染。程序模型无需 GLTF 解码，但仍需要预览名额。

两个预览用于保留运行模拟／部件编辑里的并排比较，不是给每张列表卡片常驻一个上下文。主页全屋 Canvas 不属于这个池；打开开发中心时已有逻辑会卸载背景主页场景，退出时重新建立。

## 何时占用、何时释放

| 场景 | 占用 | 释放时机 |
| --- | --- | --- |
| 模型库列表、模型选择列表、项目模型小图 | 进入可视区域后排队获取后台名额 | 成功渲染两帧并生成 PNG 后释放，仅保留普通图片；完成前滚出可视区、切页面、切后台或出错也释放 |
| 模型库大图／配置预览 | 打开并实际显示时获取交互名额 | 关闭／隐藏预览、退出编辑器、切页面、切后台标签页或失败时释放 |
| 部件动效、运行模拟预览 | 显示时获取交互名额；紧凑预览离开可视区会释放 | 退出对应页面、关闭预览、切后台、失败时释放；暂停动画不释放，因为模型仍可旋转／缩放 |
| 动效资源库代码效果预览 | 进入该页并显示时获取交互名额 | 离开页面、切后台、初始化／渲染／上下文失败时释放；暂停仍保留可交互预览 |
| 尚在等待的预览 | 不占活动 WebGL 名额，不创建 renderer | 对应界面离开时取消排队 |
| 已生成缩略图 | 不占预览名额 | 图片随组件卸载或内容更新由浏览器回收；不重新使用 GPU 渲染该图片 |

从后台恢复时，仍显示的交互预览重新排队；已成图的缩略图继续显示图片。操作系统何时释放驱动内部内存由浏览器控制，应用保证执行清理，不保证显存读数即时变为零。

## CPU 模型资源与 WebGL 名额不同

导入或编辑模型时先取得已解析资源，参数读取与预览复用这一份资源；预览实例独立持有节点与材质，几何和纹理由源资源管理。隐藏预览后释放 renderer，但编辑器仍保留一份已解析资源与待保存 File，便于重新预览和保存。换文件或退出编辑器才释放编辑器持有；最后一个实例释放后，源几何、纹理及自有 ImageBitmap 才统一销毁。这里没有无界全局模型缓存。

连续选择文件采用最新任务优先结果语义：旧请求取消，旧结果不更新界面。无法中断的解析不会假装立即释放任务名额，而是等结束后释放过期结果，再处理下一个模型。退出主页／开发中心同样取消等待和在途下载。活动加载设置 45 秒超时，超时会中止可中止的读取并反馈错误；不能中断的解码仍等结束后清理，不能保证同步阻塞的解码严格在 45 秒停止。

文件在编辑期间保留 File，不常驻 Base64 字符串；仅保存时按现有协议编码上传，尚未改成二进制上传接口。GLTF 的结构／纹理预算及完整解码 Worker 仍是后续优化，超复杂模型仍可能触及浏览器限制。

## 画质与异常

静态缩略图最高 320×200 像素、DPR=1、关闭抗锯齿，上传模型缩略图使用低成本材质，避免透射等昂贵效果；大图保留原材质，DPR 上限 1.5。完整预览、动效资源预览对初始化与 RAF 异常做局部清理；上下文丢失不会继续占用该名额。

## 验证

332 项自动化测试通过，前端构建通过。实际 5.72MiB GLB 连续解析／实例化／释放 30 轮，7860 次几何销毁事件符合预期，队列最终 active=0、waiting=0；Node 强制 GC 后第 10／20／30 轮 heapUsed 约 11／11／10MiB。此结果是 Node 中资源所有权验证，不是浏览器 GPU 内存测量。按用户要求未进行内部浏览器测试，界面效果由用户在 8101 验证。

建议人工操作：快速连续选择 A／B 文件、解析中取消、切换模型库与项目、打开／关闭大图、隐藏／显示预览、暂停与恢复动效、切浏览器后台再返回。重点观察旧文件不覆盖新文件、未再出现整页白屏、两个并排预览均能加载。
