# 在线 3D 模型库设计

## 目标与当前实现

在线模型库为可选能力，不改变本地模型上传和离线运行方式。用户可以：

- 浏览并下载 Gitea 仓库中的公开或授权模型；
- 将下载模型复制为本地自定义模型后再修改，不直接覆盖远端条目；
- 在填写作者并核对文件摘要、目标仓库后，自愿上传自己的模型；许可证固定为 MIT，标签自动使用模型名称；
- 随时关闭在线模型库，关闭后现有本地模型继续可用。

当前公开库为 <https://gitea.700117.xyz:16666/zgf/jmglink-ha-3d-model-library>，默认分支为 `main`。设备开发中心使用独立“在线模型库”页，以网格展示全部条目并提供按需加载的交互式 3D 预览、上传者信息、搜索和校验下载；“3D 模型”页下方保留经用户二次确认的直接发布。仓库为空时仍可正常使用全部本地模型功能。

正式 Home Assistant Add-on 内置上述公开仓库的匿名只读配置，不携带 Token、用户名或密码。用户安装后只要 Home Assistant 主机具备 IPv6 出站能力，即可直接浏览和下载；部署环境仍可通过 `HA3D_MODEL_LIBRARY_*` 覆盖默认值。匿名上传网关暂未实现。

## Gitea 仓库结构

建议使用独立仓库，例如 `ha3d/model-library`：

```text
catalog.json
models/<model-id>/manifest.json
models/<model-id>/model.glb
models/<model-id>/preview.webp
models/<model-id>/LICENSE.txt
```

`catalog.json` 只保存检索所需摘要；`manifest.json` 保存模型 ID、名称、版本、作者、许可证、标签、适用设备模板、尺寸、锚点、文件类型、SHA-256 和下载路径。上传模型优先使用单文件 GLB，避免外部纹理和 `.bin` 依赖；程序化模型使用 `model.json` 保存受支持的形状与材质参数，下载后仍按同一参数实时生成。

## 服务端接口

浏览器只访问 HA3D Home 后端，不直接持有 Gitea Token。建议增加以下接口：

| 接口 | 作用 |
| --- | --- |
| `GET /api/model-library/status` | 返回是否配置、仓库只读/可写能力和同步时间 |
| `GET /api/model-library/models` | 读取并缓存远端目录，支持关键字、标签和分页 |
| `GET /api/model-library/models/:id/preview` | 读取远端清单并返回卡片预览所需的安全模型配置 |
| `GET /api/model-library/models/:id/file` | 同源代理在线 GLB/GLTF，并在返回前校验路径、大小与 SHA-256 |
| `POST /api/model-library/models/:id/install` | 校验哈希后下载到本地模型资产目录，并创建本地自定义模型 |
| `POST /api/model-library/publish/preview` | 仅生成将要上传的清单、许可和文件摘要，不写远端 |
| `POST /api/model-library/publish` | 用户二次确认后发布模型文件、清单并更新目录 |

下载必须校验仓库清单中的 SHA-256、扩展名和大小上限。`readonly` 模式只允许浏览和下载；`direct` 模式只有在服务端配置写入凭证后才允许发布到默认分支。未来如开放第三方贡献，可扩展为独立分支和 Pull Request 审核模式。

## 用户确认流程

上传分两步完成：

1. 用户在“3D 模型”页保存模型后，只填写作者名称并选择“发布当前模型到公开库”；标签自动使用模型名称，许可证固定为 MIT。
2. 页面展示将上传的模型、作者、MIT 许可证、文件、大小、哈希、目标仓库与可见性；用户再次确认拥有发布权后才提交。

不得自动上传本地模型、项目、Home Assistant 实体信息、设备名称或家庭空间数据。清单只允许包含模型元数据，不写入 Gitea Token。

## 配置与凭据

建议用运行环境注入以下配置，Token 只保存在服务端秘密配置中：

```text
HA3D_MODEL_LIBRARY_GITEA_URL
HA3D_MODEL_LIBRARY_OWNER
HA3D_MODEL_LIBRARY_REPO
HA3D_MODEL_LIBRARY_BRANCH
HA3D_MODEL_LIBRARY_TOKEN
HA3D_MODEL_LIBRARY_MODE=readonly|pull-request|direct
```

使用基础认证的现有部署还可以通过 Secret 注入 `HA3D_MODEL_LIBRARY_USERNAME` 和 `HA3D_MODEL_LIBRARY_PASSWORD`。不得把这些值写入 Compose、源码、日志或导出包。

Token 最小权限为目标仓库读取；需要发布时再授予目标仓库内容写入或 Pull Request 权限。日志、导出包和前端接口不得返回 Token。

## 同步与版本

- 目录采用短时缓存并支持手动刷新，Gitea 不可用时显示上次成功缓存。
- 本地安装记录远端仓库、模型 ID、版本和提交 SHA；远端升级只提示，不自动覆盖本地修改。
- 模型更新后，由设备绑定实时解析当前模型模板，因此 2D 占位和 3D 场景同时更新。
- 删除远端模型不删除已安装的本地副本。
