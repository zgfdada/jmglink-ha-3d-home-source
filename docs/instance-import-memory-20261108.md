# 完整实例导入内存故障与修复验收

## 现场与版本边界

2026-11-08 用户报告 HAOS `.43` 在约 03:25:07 导入失败。只读查询确认 App 镜像为 `0.1.5-custom.43`，Node old-space 上限 192 MiB。上一启动周期日志最后持久记录为 03:24:32，记录整机内存压力 91%；之后出现新的宿主启动周期，App 保留退出码 255、`OOMKilled=false`。日志没有保留导入异常栈，因此不能把宿主重启的具体原因认定为已被现场日志直接证明。

版本审计确认：此前未提交的 `DevicePlatformStore.js`、`routes/instanceBackup.js` 和 `tests/instance-backup.test.mjs` 未进入 `.43` 标签。CI只验证已提交源码，无法发现工作区遗漏。这是发布范围审查遗漏，不能以“保护原有修改”为由将其视为无关文件。

另一个未跟踪脚本 `source/scripts/apply-scene-modes-small.mjs` 写死个人项目、楼层与实体，属于实例操作，不纳入通用发布。`distribution/LICENSE` 和 `docs/deployment.md` 的原有修改状态没有实质内容差异。原8101运行代码与`.43`在内置模型、MCP适配器／服务／存储以及App MCP选项上存在差异；这些代码已经进入`.43`源码，并非更多未提交修复，本次本地完整构建会消除部署落后。

## 复现

- 本地8101临时使用数据副本；原容器停止后保留，原数据和HA连接配置不作为恢复目标，不向真实HA发送控制。
- 基线使用正式`.43`镜像。Node old-space限制192 MiB，容器总内存384 MiB、无额外swap，CPU限制1核。容器预算是本地隔离限制，不声称与HAOS整机完全相同。
- 53,351,520字节的用户备份包含约27.6 MB设备编辑历史和24.2 MB设备平台数据。旧版请求约2.5秒后触发V8 `Reached heap limit`，连接中断，容器退出。
- 只补上原有未发布优化仍在同样192 MiB堆限制下失败。仅优化旧实例备份不足以解决请求整包字符串与解析对象同时驻留的问题。

## 修改

1. 仅完整实例接口使用增量JSON解析，避免同时保留整包Buffer、UTF-16字符串和解析结果。继续限制128 MiB输入，提前检查来源／类型／确认，拒绝危险键、过深嵌套、损坏JSON；其他API保留Fastify原有解析与大小限制。解析器使用锁定版本的[stream-json](https://github.com/uhop/stream-json/wiki/Parser)。
2. 完整实例导出及恢复前备份按户型、模型和历史条目写入临时文件，原子更名；HTTP导出从文件发送并在关闭后清理。模型文件缺失时中止完整备份。
3. 恢复前备份落盘后再修改实例；失败从该文件增量读取并回滚。只有拥有请求数据的恢复流程才复用历史数组，直接函数调用保留原有不修改输入的默认行为。
4. 模型解码后及时释放恢复请求的Base64字段；完整实例恢复跳过设备平台对旧历史的重复持久化，待新历史就位后统一写入。历史按条目序列化，避免整数组的巨型字符串。
5. 并发上传在读取大包之前返回409；断连或失败后释放上传占用。导入记录三个阶段及堆使用量，不记录备份正文、密钥或实体状态。前端导出直接使用Blob，正确读取服务端错误字段，并设置请求超时。

## 验收

- 更严格的192 MiB堆、256 MiB容器总内存、无额外swap和1核限制下，通过临时Ingress式前缀剥离代理及chunked上传，连续导入46,765,578字节、53,351,520字节及再次导入53,351,520字节备份，均HTTP200，约2.9～3.1秒。修复前较早方案在256 MiB连续测试第二次被cgroup杀掉，该方案没有作为最终通过结果。
- 重新导出核对户型ID、编辑历史、控件库、侧栏数量及全部上传模型内容；重启后再次核对历史和资源，9个上传模型均可读取。
- 回归覆盖192 MiB堆下重复大包恢复、UTF-8拆包、损坏／超限／危险JSON、其他接口原有限制、并发上传、断连重试，以及部分写入失败后的磁盘备份回滚。完整业务测试及Node22生产镜像构建通过。
- 本次是本地代码与8101验证，不覆盖真实HAOS导入验收。`.43`正式标签保持不变；修复需进入新的正式发布后HAOS更新才会获得。

## 避免再次遗漏

发布前执行 `python scripts/release-preflight.py`。已跟踪的实质修改不得排除，必须审查并提交；未跟踪的个人实例文件须明确记录排除原因。分别核对工作区、提交、正式标签／镜像及实际部署，不把本地成功或CI成功当作其他层已经同步。
