# 安装与首次连接操作清单

适用项目版本：0.1.5-custom.32。依据仓库 README、docs/deployment.md 与发布版 Compose 配置。教程为操作示意，不包含真实 HA 或 Docker 安装执行记录。

## 先选择路线

- Home Assistant App：已有 HAOS/Supervisor 应用商店，应用环境自动连接当前 HA。
- 独立 Docker：NAS、服务器、Docker Desktop；需要配置 HA 地址与长期访问令牌。
- 两种方式均使用已发布镜像；支持 linux/amd64 与 linux/arm64。

## App 路线

1. 从 HA 的应用商店打开仓库管理入口（不同版本可能叫应用或加载项）。
2. 添加安装仓库：

```text
https://gitea.700117.xyz:16666/zgf/jmglink-ha-3d-home-custom
```

3. 安装 JMGLink HA 3D Home Custom，启动，检查日志，打开 Web 界面。
4. 通过应用环境自动连接当前 HA，检查连接状态与实体同步，再创建/导入项目。
5. App 默认使用提供的网页入口；Docker 的 8101 端口不是 App 必须开放的端口。

## Docker 路线

先准备已运行的 Docker 和 Compose，在部署目录保存本目录附带的 docker-compose.release.yml。

```shell
docker version
docker compose version
docker compose -f docker-compose.release.yml pull
docker compose -f docker-compose.release.yml up -d
docker compose -f docker-compose.release.yml ps
docker compose -f docker-compose.release.yml logs --tail=100
```

- 浏览器：`http://主机IP:8101`，这里是容器主机，不一定是 HA 主机。
- 端口：`8101:8099`；冲突时改左侧，右侧与容器配置保持一致。
- `./ha3d-data:/data` 保存项目和配置；`./ha3d-assets:/assets` 保存模型素材。
- 保留 `entrypoint` 独立入口；`latest` 会随发布变化。
- 界面字段：Home Assistant 地址、API Key / 长期访问令牌、保存并连接。
- HA 地址须能从容器环境访问；其他主机上的 HA 不能用容器自己的 localhost 代替。
- 在 HA 用户资料的 Security/安全页创建长期访问令牌，创建后仅显示一次。令牌不要放进公开素材、Git 或录屏。

## 验收与维护

- 网页打开 + HA 已连接 + 真实实体可见。
- 已连接但无三维设备时检查项目和绑定。
- 已有部署先备份，再迁移旧目录；不要两个容器共写一份数据。
- 升级保留持久化数据；较大调整前导出项目并备份数据与模型。
