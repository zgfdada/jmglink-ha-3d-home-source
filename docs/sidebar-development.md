# 侧边栏开发中心

本功能处于本地开发版本，尚未发布到正式镜像。

主页展示自定义侧边栏，右侧内嵌竖向导航，默认页面为天气。主页不提供控件编辑；右下角页面工具与语音按钮相邻。打开主页右下角页面工具 → “侧边栏开发中心”，进入以下两个页面。

## 控件开发

选择控件或新建自定义控件，筛选并绑定 Home Assistant 实体。右侧显示该实体属性和实时预览。内置天气可自动查找天气实体，也可以显式绑定。

自定义控件使用 HTML 模板、CSS 和 JavaScript。模板字段写作 `{{state}}` 或 `{{attributes.temperature}}`；脚本接收 `entity`，返回模板使用的数据，例如：

```js
return { title: entity.name, value: entity.state, unit: entity.attributes.unit_of_measurement };
```

```html
<article class="card"><small>{{title}}</small><h2>{{value}}</h2><span>{{unit}}</span></article>
```

CSS 只影响控件内部。JavaScript 在沙箱 Worker 中运行，执行上限 1 秒；控件无法访问主页面、访问令牌或网络，也不会调用 HA 服务。HTML 中的脚本、表单、外部资源和事件处理器不执行。此版本用于实体状态展示，不提供自定义设备控制动作。

支持复制控件、删除未引用控件、导入和导出布局。被页面引用的控件不能直接删除，应先移除页面中的引用。

## 页面设计

左侧新增和选择导航页面，并从控件库添加控件。中间画布呈现侧边栏整体效果，导航始终位于内容区内部右侧。选择控件后，可在右侧覆盖绑定实体、调整高度、移除或调整顺序；也可以拖动控件排序。

页面内容采用纵向组合布局，超出可用高度时滚动。侧边栏总宽度可在 280–560px 范围调整，移动端使用紧凑展示。右侧可修改导航名称、图标和顺序。至少保留一个页面。交互预览会关闭设计选框。

## 保存、发布和备份

- **保存草稿**：仅更新开发中心草稿，主页不变。
- **发布到主页**：校验并保存整个草稿快照，主页读取已发布版本。其他终端刷新即可生效。
- **重新加载**：读取服务端草稿；未保存修改会先提示。
- 多终端并发保存采用 revision 检查，过期草稿返回冲突，不会覆盖其他终端修改。
- **导出布局 / 导入布局**：单独备份或迁移侧边栏的所有页面、控件和代码。导入后需再次保存或发布。

配置按项目保存在数据目录的 `sidebar-workspaces.json` 中，写入时保留 `.bak`，并通过临时文件原子替换。部署时备份整个 `/data`。当前旧版项目导出不包含此独立文件，请同时使用“导出布局”备份侧边栏。

## 实现约束

主页、控件预览、页面画布共同调用 `sidebar-development/renderer.jsx` 中的 `SidebarPanel` / `WidgetRenderer`，禁止为设计器复制另一套渲染逻辑。服务端路由为 `GET /api/sidebar/:project` 与 `PUT /api/sidebar/:project/draft|publish`。文档格式 `ha3d-sidebar-v1` 的校验在 schema 包中前后端共用。

侧边栏实体绑定加入实时同步集合；新建实体绑定后保存草稿即可持续接收状态更新。只在当前应用页面允许写配置，阻止跨站写入。
## 当地日照与夜间场景

主页优先读取 Home Assistant 家庭所在地的 `sun.sun` 太阳高度角，在太阳高度 -6° 至 10° 之间平滑调整三维环境光、半球光和主光。日落进入夜间主题，日出恢复日间主题；不会修改实际灯光设备状态，也不降低灯具自身发光。

若没有高度角，则使用 HA 提供的下一次日出、日落时间或地平线状态；完全缺少太阳数据时才回退到终端时间。太阳实体参与实时订阅，页面另每分钟检查一次时间边界。

## 导航居中与环境光预览

侧栏导航按钮组在可用高度内自动居中，过多导航仍可滚动。主页右下角工具和语音按钮放在同一 Flex 容器中，菜单点击展开，不依赖悬停或单独的像素定位。

打开工具 → 环境光，可通过 0–100% 滑块或夜间、黄昏、白天预设查看不同场景光照效果。点击“恢复自动环境光”重新跟随 HA 太阳信息；手动模式只作用于当前页面，刷新后恢复自动，不操作真实设备。

## 玻璃覆盖与侧栏收放

三维 Canvas 铺满整个主页，侧栏以低不透明度玻璃浮在同一画布上。侧栏不再占用、裁剪或分割 Canvas，所以移动或放大到侧栏下方的模型仍会透过模糊玻璃显示，也不会在侧栏右侧形成背景竖带。取景避让只调整相机，不改变画布覆盖范围。

侧栏下方提供“收起侧栏 / 展开侧栏”按钮。收起时移除侧栏交互及占位，并调整相机取景；展开入口始终保留。显示偏好只保存在当前浏览器，项目页面配置不受影响。

## 入口与导航栏收放

主页工具菜单分别提供“设备开发中心”和“侧边栏开发中心”，侧栏开发入口不再放在户型编辑器中。收放按钮固定在导航栏内部最下方，与居中的页面按钮组独立布局。收起只隐藏左侧内容，导航栏保持可见；点击导航页面可同时展开内容。即使页面按钮组为空，收放按钮仍保留。


### 天气示例与普通控件
天气示例也是普通 HTML / CSS / JavaScript 控件，可以查看、修改、复制和删除全部代码。旧版内置天气自动迁移，保留实体绑定与页面引用。所有控件都可设置未绑定时自动选择的实体域。JS 接收 `entity` 和 `widget.name`，返回模板数据；HTML 使用 `{{字段}}`，数组可用 `data-each="forecast"` 重复节点（最多 100 项）。模板值按文本插入，主页和两个设计预览共用同一沙箱渲染器。

实体绑定使用搜索输入框和下拉列表组合，按名称、friendly_name 和实体 ID 的任意片段实时筛选，忽略大小写。无结果时显示提示，搜索不会自动改变已有绑定。

### 能耗示例
能耗摘要与天气同放在「主页 ⌂」导航内，基于 chjspp520/electricity-info-card v3.3.0 的原卡片代码适配，原项目：https://github.com/chjspp520/electricity-info-card 。ECharts 5.4.3 随本地资源提供。HTML/CSS/JS 仍为普通可编辑控件，交互脚本在无同源权限、禁止网络请求的 iframe 中运行，只接收实体快照；不提供 HA 令牌、API 调用、历史接口及缴费服务。自动选择带 monthlist 属性的 sensor；也可通过搜索绑定其他符合原卡片格式的实体。阶梯单价与账期沿用原卡片默认值，请按实际户号在 JS 中配置；预估结果仅为原卡片算法结果。主页、控件预览和页面设计使用相同渲染器。导航支持独立十六进制图标颜色。

能耗自动汇集带 monthlist 或 yearlist 的户号实体，通过原卡片多户栏切换。实体数据通过 postMessage 增量推送，保持 iframe 和卡片实例，不因 HA 状态广播重载当前视图。

能耗隐藏阶梯电价区。本月、上月与年度摘要点击后，通过经过来源校验的 iframe 消息打开顶层 Portal 浮动详情，保留户号与目标统计视图；浮层可点击关闭按钮、遮罩或按 Esc 关闭，不受侧栏毛玻璃与滚动区域裁剪。

### 确认稿布局与主题
主页去除旧标题区，控件距内容栏两侧各 8px，天气标题右侧显示本地日期、时间和星期。天气图标、温度数值、单位作为一个整体居中，单位留出 7px 间距。所有控件由沙箱报告自然内容高度，仅侧栏整体滚动；页面设计不再提供无效的固定高度滑块。主页、独立实时预览及页面设计共用同一表面组件，只有外壳绘制背景，iframe 内部透明，避免嵌套模糊、渐变和圆角造成色带。
白天为蓝灰透明底和浅字，黄昏/夜间为浅灰透明底和深字；导航、环境光工具与能耗浮层使用同一规则。黄昏场景背景采用暖灰橙色渐变，并随日照强度平滑过渡。开发中心编辑区为白底，预览保留实际主题。
电费卡片保留摘要布局，通过月/年按钮打开原卡片的交互统计，账单金额可打开缴费记录。名称顺序为手动显示名称、实体 `title`、客户姓名属性、实体友好名称；不会用序号替代已提供的真实名称。显示名称在控件开发中可编辑。
打开/关闭设备控制面板不再触发相机初始构图；窗口尺寸、楼层、视角预设及显式重置仍保留原适配行为。

### 设计 Skill 下载
展开侧栏下方提供「下载侧边栏控件设计 Skill」文本链接：`agent-skills/ha3d-sidebar-widget-design.zip`。服务根据清单即时生成 ZIP；可读文档入口为 `agent-skills/ha3d-sidebar-widget-design/SKILL.md`。包内包含当前风格规范、接口说明、可导入默认示例、对应 schema 和校验脚本，不包含用户运行数据或凭据。修改默认模板后，应同步更新包内 references 与 assets/sidebar-example.json，测试会检查示例与当前模板一致。

### 多实体绑定

控件开发和页面设计均支持按名称、实体 ID 的任意片段搜索，并勾选多个实体。绑定区下方显示实际生效的名称和 ID；自动选择也显示具体结果。页面绑定优先于控件默认绑定；清空表示不使用实体，恢复默认则重新继承。`entityIds` 为数组时使用精确列表，为 `null` 时继承旧的 `entityId` 或自动规则。带自动选择属性的控件默认匹配全部实体，普通天气默认匹配第一个天气实体。渲染器与实时订阅共用相同解析逻辑。

页面设计直接点击画布控件选中，不显示页面图层列表。

### 运维与音乐页面

- 运维页复用 HA 仪表盘的离线统计文本、缓存刷新实体，以及耗材总开关和每项显示条件实体。显示判断严格使用原条件实体的 `on` 状态；低余量阈值继续由 HA 决定，不在卡片内另设固定数值。原页面中的 warning/critical 只是颜色告警，不能当作显示阈值。
- `operationsWidgetCode(settings)` 的设置包括 `offline`、`refresh`、`master` 和 `rules`（每项 `condition`、`entity`、`name`）。绑定列表必须包含统计、缓存、全部条件和数值实体。当前实例配置保存在运行数据中，公开样板不包含用户实体 ID。
- 音乐页复用现有 HA 资源 `songloft-card 2.1.1`，提供歌词、搜索、歌单、队列和播放控制，可展开大浮层；绑定 Songloft 媒体实体，按快照增量更新。
- 控件通过父窗口桥接请求操作；父窗口核对绑定实体，服务端按已保存控件的动作声明、实际绑定范围和当前 HA 服务目录做通用校验。HA Token 保留在服务端，封面通过同源图片代理读取。
- 播放及音量控制会作用于绑定的真实播放器。验证时未触发播放、切歌或音量变化。

音乐卡片搜索使用按钮/回车直接调用受限桥接；歌词居中通过容器和歌词行的实际矩形计算，不依赖页面偏移或分辨率。侧栏保留 overflow:auto，导航按钮高度 56px；运维功能区使用 20px 间隔。

设备控制面板在主页内使用 device 主题变量，背景与侧栏卡片一致，内部固定浅色文本改为主题文字。窗帘状态不使用点光源，只在模型轨道材质上提供弱自发光，避免扩大房间照明范围。

### 通用控件协议（2026-10-23）

HA → 3D Home：按控件绑定共享状态快照。3D Home → HA：控件使用 ha SDK，宿主附加项目、草稿/发布版本、页面实例及控件身份；服务端从保存布局读取动作声明并解析真实目标，不信任客户端自报权限。服务目录读取 HA，不包含固定设备 ID、集成名称或专用服务清单。

开发中心可搜索服务、添加动作、配置目标和 JSON 参数，并插入按钮 HTML。脚本使用 ha.callService、ha.runAction 和 ha.onStateChange；音乐完整 UI 代码已进入控件 JS。权限需先保存草稿，主页使用发布声明。

### 房间控件样板

`packages/schema/src/room-widget.js` 的 `roomWidgetCode(settings)` 接收房间名称、可用房间、实体字段、模式选项和 actions。灯光数量解析绑定灯组成员；模式选项使用 HA 原始值。窗帘使用中心对开图示和透明 range，拖动只更新图示，释放调用 `cover.set_cover_position`。空调显示设定/室温，按实际属性列出风速、工作模式、摆风和预设；详情复用同一控件浮层。所有实体 ID 仅在用户运行布局配置，不写入样板或后端。

窗帘拖柄按按下位置记录开合度，以相对位移计算；仅松手且数值改变时提交，单击不发送动作。状态变化使用独立逐帧进度更新布幅和拖柄，避免节点重建打断 CSS 过渡；即使实体只回报最终位置，也从当前可视位置缓慢补间到目标，使用 curtainTravelMs（默认全行程 18000ms）按距离估算动画时长。拖柄目标与布幅可视进度分离，最终值回报不跳帧。拖动中暂停补间以保持跟手。空调以单个开关按钮切换，详情按真实能力平铺选项并保留原始提交值。

房间集合使用 `roomConfigurations`，各项独立配置名称、模式实体/选项、actions、`actionAliases`、`lightEntities`、`curtains`、`parameters` 和 `curtainInfo`。`lightEntities` 仅统计开启数量，不生成逐灯控件。双层窗帘通过实体标识分别保存模拟动画进度；切换房间不修改3D相机。控件权限仍由最外层 actions 和实际绑定列表限制，个人配置只保存在运行布局。

### 按楼层设计

开发中心楼层选择与当前主页楼层关联，布局读写以实际floorId为作用域。旧project键继续保存原第一层布局，并记录floorId防止重排误绑；其他层以独立键保存，空白起步。动作转发也读取同一floorId的已保存草稿/发布声明，不允许从F2调用仅存在F1的控件。楼层栏来自项目floors，编号F1起，与侧边栏同一上下边界，选项居中；小屏设备面板避让楼层栏。


## 默认布局与图片显示

初次使用仅包含“主页”导航和一个天气代码控件。能耗、运维和音乐是可选代码示例，不自动创建导航或注入已保存的草稿/发布布局；用户已有控件及导航保留。新楼层仍从空白布局开始。

HAOS 图片代理必须保留 HA REST 地址中 `/api` 之前的前缀，例如 `http://supervisor/core/api` 对应 `/core/api/media_player_proxy/...`。图片源仍限制为 HA 同源的 `/api/`、`/local/` 路径，不允许跳转转发凭据。

隔离 iframe 无法直接依赖 HA Ingress 登录 Cookie。`widget-images.js` 由宿主页按绑定实体从相对图片代理地址读取，使用 same-origin 会话，限制图片类型及 5MB 大小，并缓存当前图片；控件快照中 `pictureData` 和已归一化的 `attributes.entity_picture` 是 data URL。`ha.imageUrl()` 保留兼容的 fragment，旧控件附加缓存参数不会破坏图片内容。原始 HA 状态及服务参数不被修改，控件不会获得登录凭据。

## 控件、导航页与完整实例迁移

开发中心底部提供「导出当前控件」「导出当前导航页」「导出整层侧栏」以及统一导入入口。当前控件跟随预览选中项；导航页包含引用控件的代码、默认实体与实例绑定。控件和页面导入追加到草稿并重映射冲突 ID；整层导入替换本楼层草稿。导入后需保存或发布；控件片段需添加到页面。

全局迁移请使用主页工具菜单「导入导出」，覆盖所有户型、所有楼层及设备平台资源，不能用某一层侧栏 JSON 替代。恢复前自动保存当前业务快照，HA/Hermes 连接信息不迁移。外部资源链接仍需可访问。

控件开发默认进入「实体与配置」，代码通过独立页签编辑；默认实体直接搜索多选，已生效实体在下方展示。右侧预览提供主题与尺寸切换，实体属性支持按路径或值搜索、JSON 查看和路径复制。该页隐藏楼层入口，但本次仅调整 UI，不迁移或合并原有各楼层工作区数据。

代码编辑使用 CodeMirror，默认自动换行，支持行号、语法高亮、400ms 延迟校验及手动校验。JavaScript 用 Acorn 检查语法，兼容转换脚本顶层 return；HTML/CSS 通过对应语法树报告错误。仅检查语法，不执行代码，不代替运行时数据验证；点击错误可定位行列。

控件开发「导入 / 导出」菜单固定四项：导入控件、导出当前控件、导入控件库、导出控件库。控件库包格式 ha3d-sidebar-library-v1，version=1，widgets 保存全部控件，不携带导航页或侧栏布局；导入追加并重映射冲突 ID。页面设计提供导航页与整层侧栏各自的导入导出。每个入口只接受对应类型，避免误把侧栏文件导入控件库。

页面设计使用最左侧竖向实际楼层选择；切换未保存草稿需确认。导航可以在左侧列表拖动，也可以直接拖动预览栏的导航按钮（鼠标/触屏）。排序只作用于当前楼层草稿，保存或发布后持久化。右侧区分控件与页面设置；可见性隐藏只影响展示，编辑态保留隐藏实例便于重新启用。预览直接复用生产渲染器，不增加素材背景。

删除控件和移除页面实例均需在红色危险操作复核弹窗中确认；移除实例保留库控件与其他页面实例。被引用的控件需先移除引用。主题变化通过消息同步至交互控件和数据转换控件，不重载 iframe；画布背景也随预览主题改变。


## 事件与运维可选控件（待发布）

事件导航页直接展示原移动通知日志实体的 attributes.entries，不增加分类或虚构未读数量；保留原时间、标题、正文、来源与状态。sent_to_ha 只表示已交给 HA，不代表手机已收到。未绑定、离线和空记录有明确空态；文本通过 textContent 渲染。

monitoring-widgets.js 的 eventsWidgetCode(settings) 与 hostResourcesWidgetCode(settings) 可生成隔离前端控件。主机资源需要明确绑定整机 CPU、内存百分比、已用和可用内存四类实体；不把 Core 进程用量当作整机，不把无效值显示成零。settings 中的个人实体 ID 仅保存到用户运行布局。

operations-widget.js 的 offlineStatisticsWidgetCode 和 consumablesWidgetCode 为两个独立控件；保留旧 operationsWidgetCode 兼容组合样板。耗材使用原 HA 显示条件，不猜测替换原阈值。统计刷新声明明确缓存目标，通过现有通用动作接口调用；成功调用后核对有效统计，未变化时提示无变化，无效结果继续等待并在超时后说明上游异常。

若缓存实体一直 unknown，先检查 HA command_line 的命令运行时间与 command_timeout。统计脚本查询 recorder 最新状态时，应使用现有 metadata_id/last_updated_ts 索引，避免按 state_id 排序大量历史记录导致超时；这属于用户 HA 配置维护，不为 3DHome 后端加入专用统计逻辑。新安装仍默认仅主页与天气。

事件与运维使用宿主统一主题和玻璃背景，随白天、黄昏、夜间变化；不单独固定蓝底和白字。保持资源双列、彩色进度条、大号离线数、独立耗材布局；刷新仅保留离线统计卡片右上角按钮。

运维离线数量使用固定矢量断链图标，设备明细逐行使用灯泡图标，避免 Unicode/Emoji 在不同平台显示不一致。耗材档位保留 HA 原值，以 22px、800 字重显示。
