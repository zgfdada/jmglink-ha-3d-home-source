## 独立 Docker

使用根目录的 docker-compose.release.yml；安装、升级仅需拉取镜像。

# Docker 镜像部署

安装 Docker Engine / Docker Desktop 和 Compose。无需 Git、Node.js 或其他开发工具。

1. 下载仓库根目录的 `docker-compose.release.yml` 到部署目录。
2. 检查镜像版本、端口和持久化目录。
3. 拉取并启动：

```shell
docker compose -f docker-compose.release.yml pull
docker compose -f docker-compose.release.yml up -d
docker compose -f docker-compose.release.yml ps
```

打开 `http://主机IP:8101`，在界面配置 HA 地址与访问令牌。

Compose 通过独立入口运行已发布的同一多架构镜像。`./ha3d-data` 保存运行数据，`./ha3d-assets` 保存模型素材，`./ha3d-mcp-private` 保存 MCP 权限、连接及加密凭据。Compose 项目名为 `3dhome`，单个 `ha3d-home` 服务使用一个镜像同时运行网页和 MCP；默认启用 MCP，地址为 `http://主机IP:8112/mcp`，管理页为 `http://主机IP:8101/mcp-admin`。仅向可信网络开放；可通过 `.env` 的 `HA3D_MCP_ENABLED=false` 关闭，已有同名变量优先。旧部署迁移时改为原有目录，先停旧容器；不要同时写同一份数据。
