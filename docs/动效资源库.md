# 动效资源库（本地开发版）

入口：设备开发中心左侧第四项「动效资源库」。本功能在 8101 本地开发版提供，尚未发布新的 HAOS 安装版本。

## 管理资源

同页从左至右为资源列表、逻辑代码、实时效果与参数。JavaScript 标签显示实际参与运行的 `update(ctx)` 函数，表面扫光另有 GLSL 片元与顶点代码。支持行号、Tab 缩进及 Ctrl+Enter 校验预览。代码编辑中保留上一次已应用效果；语法或执行错误不会覆盖已应用代码。

修改后点击「校验并更新效果」，确认实际效果再点击「保存动效」。没有应用的代码、执行错误、运行超时或着色器编译失败均不能保存；取消修改恢复上次保存版本。仍可通过右侧表单调整默认参数，代码通过 `ctx.params` 读取它们。

九种内置动效：位移、角度、持续旋转、缩放、显隐、颜色、发光、路径流光、表面扫光。可按名称或用途搜索，按内置／自定义及变换／外观／光效筛选。

选中卡片后，在同页右侧编辑名称、说明、默认参数及过渡时间。预览使用与主页相同的 3D 动效引擎；可以切换条件满足／未满足、暂停、旋转和缩放。预览不连接或控制真实设备。

- **保存动效**：保存当前资源参数，供之后选用的规则使用。
- **复制动效**：保留现有资源，建立可编辑的新资源。
- **新增动效**：选择基础类型并配置参数，建立通用可复用资源。
- **恢复默认**：将内置资源还原为随程序提供的设置；内置基础类型不可修改或删除。
- **删除资源**：仅删除自定义条目，需要在界面再次确认。已有设备规则仍保留可运行快照。

切换资源或离开资源库前，需要保存或取消尚未保存的修改。其他页面同时更新资源库时，本次保存会提示冲突；取消修改并重新进入可加载最新内容。

## 在设备中使用

1. 打开设备项目，映射自身或额外实体的能力。
2. 在「3D 外观 → 部件动效」选择部件、新增规则。
3. 在「动效资源」中选择内置或自定义资源，其默认参数和过渡时间复制到当前规则。
4. 设置能力、触发条件或连续数值映射；可以针对当前设备调整复制后的参数。
5. 校验、模拟预览后保存规则。

资源库不绑定实体、模型部件或触发条件。相同资源可用于车辆、家电、灯具等不同设备；具体使用哪些能力与部件由设备规则决定。

已经保存的规则保留独立参数快照。修改或删除库内资源不会自动改变现有设备；如需采用新默认值，在该规则中重新选择对应资源，然后校验保存。旧规则升级后仍可正常编辑、播放。

## 备份与扩展

完整实例及设备平台备份包含动效库。恢复旧备份时，如果没有动效库字段，保留当前库。导出单个设备包时，动效规则携带完整参数，接收方无需预先安装同名资源即可播放。

界面可编写基于现有九种基础类型的运动与着色算法，例如三轴往复位移、非匀速转动、自定义光点数量和间距、脉冲发光、扫光边缘及混色。新的基础几何类型或输出通道仍需扩展源码中的类型、参数表单及引擎。

## JavaScript 接口

定义同步函数 `update(ctx)` 并返回结果对象。可定义辅助函数和实例内变量；同一代码可复用，但各模型／规则实例的闭包状态相互隔离。输入：

| 字段 | 含义 |
| --- | --- |
| time / delta | 规则累计激活时间／帧间隔，单位秒，暂停时不累积 |
| input | 原始能力的简单状态值，触发条件仍由设备规则管理 |
| value | 已完成数值映射与过渡的输出值 |
| phase / angle | 原有积分进度／角度（度），可在代码中重写运动方式 |
| mapped / weight | 是否启用数值映射／当前过渡权重 |
| params | 基础类型、轴、颜色、速度、宽度、路径等默认参数 |

示例：无需修改参数表单，直接改变运动算法：

```javascript
function update(ctx) {
  return { offset: [0, Math.sin(ctx.time * 2) * 0.25, 0] };
}
```

| 类型 | 输出字段 |
| --- | --- |
| 位移 | offset: [x,y,z]，或沿默认轴的 value |
| 角度／持续旋转 | angle，单位度 |
| 缩放／显隐 | value／visible |
| 颜色 | color（#RRGGBB）、mix（0–1） |
| 发光 | wave、intensity（0–20）、color |
| 路径流光 | progress（1–32 个 0–1 的路径进度值）、color、opacity、trailOpacity |
| 表面扫光 | phase、color、width（0.02–1）、intensity（0–20） |

代码在独立 Worker 中运行，按代码复用运行器、按实例隔离状态，不直接访问模型对象、DOM 或 HA 服务。网络、存储及子 Worker 接口被禁用，网络还受独立 CSP 限制。初始化和执行有超时保护，输出经过有限值、范围和形状校验；最多并行 16 种代码，实例释放后终止不再使用的运行器。不要使用异步函数返回 Promise。

## GLSL 接口

表面扫光可直接编辑实际顶点、片元着色源码。已有 uniform：`uColor`、`uAxis`、`uRange`、`uPhase`、`uWidth`、`uIntensity`、`uWeight`；已有 varying：`vScanPosition`、`vWorldPosition`、`vWorldNormal`。可改变光带形状、透明度、边缘与混色。预览会显示 GPU 编译错误；修正并重新校验后才能保存。GLSL 仅作用于独立光效叠层，不改原模型几何或材质，不参与点击拾取。

JavaScript 与着色代码通过资源、设备规则快照、单设备包及完整实例备份保存；主页和编辑器共用运行引擎。旧规则没有代码字段时继续使用原有内置算法。
