# 第一人称室内漫游

适用于 0.1.5-custom.40 及后续版本，第一版仅浏览当前楼层，不改变户型或真实设备状态。

## 进入和操作

在主页右下角的页面工具中选择“室内漫游”，再点击房间内远离墙体和家具的空地。无效落脚点会提示重新选择，不自动把人物放入模型。

| 操作 | 电脑 | 手机／触屏 |
| --- | --- | --- |
| 移动 | WASD 或方向键 | 左下角摇杆 |
| 环顾 | 按住鼠标左键拖动画面 | 拖动画面 |
| 加速 | Shift | 暂无 |
| 自由鼠标环顾 | 点击“锁定鼠标”，随后移动鼠标 | 使用拖动环顾 |
| 释放鼠标操作设备 | Alt；不支持锁定时继续用拖动 | 松开拖动后直接点设备 |
| 设备控制 | 自由鼠标状态直接点设备 | 点设备，沿用浮动控制面板 |
| 退出 | Esc 或“退出漫游” | “退出漫游” |

退出恢复进入前的相机位置、朝向、视角范围和环绕目标。切换楼层／项目或打开使场景挂起的开发中心时退出漫游，避免跨楼层继续使用旧碰撞数据。进入时暂停自动旋转；常规侧边栏暂时隐藏，退出恢复其原有显示偏好。

## 碰撞和显示

- 默认眼高约 1.6m、人物水平碰撞半径 0.18m、正常步速 1.4m/s、Shift 2.4m/s；低楼层会限制眼高。
- 墙体按墙线与厚度阻挡，门洞按位置、宽度和净高放行，窗户不可通行。长步长细分并支持沿墙滑动。
- 家具使用旋转后的矩形占地轮廓，高于人物的悬挂家具不阻挡；复杂凹形、异形或自定义模型不会做逐三角形碰撞，可能比实际模型更保守。设备模型本体暂不单独加入碰撞。
- 漫游仅允许当前户型范围内移动；不支持重力、跳跃、楼梯、跨楼层或第三人称角色模型。
- 墙体在漫游中不透明，显示室内天花板并遮光。门扇在此模式临时隐藏便于通行，退出后恢复真实门磁驱动的显示；不调用门锁或开门服务。
- 日月光、环境光和设备联动继续生效。夜晚室内暗时可调环境光；漫游显示实体天花板，因此按完整室内遮光处理。

## 实现和验证

`first-person-navigation.js` 构建墙段／门洞、房间可行走区域与家具 OBB；`walkingDelta` 限制单帧时间并归一化斜向输入，`walkStep` 分步防止越墙。导航几何签名不包含模型文件正文，实时实体状态不改变几何时不会重建输入绑定。

`first-person-controller.jsx` 使用现有 R3F 相机，不新建 Canvas；选点通过视线与地面平面相交后进行碰撞校验。独立保存／恢复相机状态，漫游期间禁用 OrbitControls 和自动适配，窗口失焦、页面隐藏、指针取消、退出或卸载时清空输入并释放监听。键盘输入框操作不触发人物移动；Pointer Lock 不可用时提示使用拖动。

移动中按需请求帧，静止时不额外启动后台 RAF。回归包含墙体、双向门洞、低门／窗户、旋转家具、墙角、非矩形区域、时间步长和相机恢复。实际浏览器、触屏及不同设备性能仍需用户在 8101 验收。
