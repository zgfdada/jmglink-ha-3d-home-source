# 窗帘轨道编辑

适用范围：本地 8101 开发版，尚未发布正式新版本。入口为「房间布局编辑 → 选择窗帘设备 → 右侧窗帘轨道」。适用于内置布帘／纱帘模型，百叶／卷帘继续使用宽高配置。

## 配置步骤

1. 在模型样式中选「遮光窗帘」或「纱帘」。遮光帘低透光，纱帘使用高透光材质；两者共用同一套轨道配置。右侧取消原来的「模型缩放」，以实际米制尺寸配置。
2. 点击直线、L 形、U 形预设，或点击「自定义绘制」从空路径开始。预设初始长边 3.30 m、短边 0.60 m，可继续编辑。
3. 在原有 2D 户型画布点击添加转角。双击或 Enter 结束当前绘制，拖动编号圆点调整节点。支持网格、墙面偏移和接近水平／垂直吸附；Shift 强制锁直。关闭顶部「吸附」后自由定位，Shift 仍可锁直。按住空格可以平移画布，滚轮缩放保持原有行为。
4. 选择线段输入精确长度；改长后下游节点一起移动，保留后续各段的长度和方向。可以在线段中点插入节点，通过画布圆点或「选择节点」指定并删除任意节点（至少保留两个）。
5. 「吸附距墙面」只影响之后的绘制和节点拖动，不自动挪动已有路径。转角使用圆滑过渡，短线段会自动限制圆角范围。
6. 通过「距顶」「帘布高度」「离地」配置安装位置；高度与离地距离联动，限制在当前楼层以内。不再用模型整体比例改变轨道／帘布尺寸。
7. 选择起点收拢、终点收拢或两端对开。右侧立体示意和开度滑块只模拟外观，不发送 HA 服务调用。
8. 有效轨道修改自动写入项目，并按原有自动保存流程保存，无需点击应用。少于两个节点、自相交等无效路径保留在编辑态，不覆盖最后有效轨道。参数调整／节点编辑时可直接点击其他设备；全画布捕获仅用于自定义绘制，完成绘制后恢复设备选择。Esc、切换设备／楼层或离开 2D 结束编辑，已保存的有效修改保留；继续绘制和节点撤销仍可使用。

## 状态与兼容性

- 一个连续轨道对应原来绑定的一个 HA 窗帘实体，不新增或替换实体。读取 `current_position`，HA 0% 为关闭、100% 为打开；没有位置属性时按原有 open／closed 状态回退。
- 模型沿整条轨道弧长移动，两端对开在轨道中间分离。完全打开仍保留 10% 轨道长度作为收拢褶皱；中间和转角不会被当作独立窗帘。
- 原有布帘的缩放值仅用于换算旧宽高、保留外观。配置新轨道后移除该实例 scale，以路径米制坐标、帘布高度和距顶配置为准；旋转和 X／Y 平移仍可使用。
- 轨道最多 64 个节点，最短线段 0.05 m。自相交、闭合、原路折返、无效坐标不能应用。
- 双层纱帘／布帘分别绑定实体、分别绘制轨道。本次不引入多电机同步规则。

## 实现与验证

`packages/schema/src/curtain-track.js` 统一数据归一化、校验、路径变换、圆角、弧长、三种开合区间及绘制吸附。项目保存／导入通过同一 schema 保留 `curtainTrack`。轨道节点以设备原点及 Y 轴旋转为参考，坐标单位为米，不应用设备模型缩放。

`curtain-track-editor.jsx` 在既有 SVG 画布末层添加路径编辑；有效路径通过 `curtain-placement.js` 校验后直接进入项目历史和保存，无效中间态不覆盖项目，相同轨道不重复写入。立体示意为 SVG，不申请 WebGL 预览槽位。实际模型由 `curtain-model.js` 创建一根轨道及一到两片连续褶皱帘布，状态变化更新已有顶点缓冲，不逐帧新建几何体；资源在轨道／材质变化和卸载时释放。动画仅在状态过渡时请求后续帧。

自动验证覆盖项目序列化往返、旧尺寸换算、旋转坐标一致性、异常路径、圆角连续性、三种开合方式、墙面吸附、尺寸修改、3D 缓冲复用／资源释放及打开后中间区域的射线穿透。按用户要求不使用内部浏览器，实际绘制手感及页面显示由用户在 8101 验收。

## 设备替换与控制面板

编辑器设备名称为可展开的绑定选择器，支持名称／实体 ID 搜索。可替换未被其他摆放占用的同类型设备；位置、旋转、轨道保留，旧项目绑定身份随新实体更新，便于复制粘贴后重新绑定。移除位置区域的手动「所属房间」下拉框，保留原有位置判断和 HA 实体归属信息。

3D 主页的设备控制面板统一为浮层，点击窗口外部关闭并拦截该次画布点击；移除左上角返回键。电脑使用详情浮层，手机仍使用适应屏幕的浮动面板，均支持窗口外部关闭。相机实时画面继续使用独立播放器弹窗，不改变原有媒体生命周期。
