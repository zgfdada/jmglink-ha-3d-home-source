# 额外实体选择与能力映射

入口：设备开发中心 → 打开项目 → 基础信息 → 额外关联实体。

主设备绑定可选。没有自身 HA 设备时，直接在同页搜索实体名称、实体 ID 或来源设备，选择定位跟踪器、充电传感器等额外实体后点击「保存额外实体」，即可继续能力映射、模型与部件动效配置。项目会在本应用中作为独立设备供摆放，不向 HA 注册虚假设备，也不改变原实体归属。没有选择任何额外实体时，发布检查仍提示补全数据源。

可按类型筛选、仅看已选，筛选不会清空选择；取消更改恢复上次保存。历史已选但当前不可用的实体仍保留，便于移除或等待恢复。页面只选择实体，不配置联动或动效。

保存后进入原有「能力与属性映射」：将额外实体映射到已有能力，或使用「新建能力并映射」。例如将 `device_tracker` 的 `state` 配置为「车辆位置」字符串状态能力，再到「3D 外观 → 部件动效」中选取这个能力。到家值需要使用跟踪器实际提供的原始状态，例如 `home`。

车辆模型默认显示时，可设置「车辆位置不等于 home → 显隐 → 隐藏」，条件结束后恢复原状。这样在家显示、离家隐藏。显隐、位移、颜色、发光、流光、扫光和数值映射均沿用原有动效逻辑，不增加独立规则系统。未知、不可用或 HA 离线遵循现有动效的恢复行为。

额外实体不会改写主设备绑定，也不会改变该实体在 HA 中的归属。取消关联已被能力使用的实体时，该能力映射会解除，能力定义与动效规则保留并提示重新绑定。主设备自身实体重新保存时保留额外关联；仅额外实体的项目之后绑定真实主设备时，也保留仍属于额外来源的选择与能力映射。实体注册表改名时同步更新选择和能力映射。

这些选择属于当前 HA 实例的绑定数据。便携设备包仍只携带能力和动效定义，不自动导入实体实例绑定。功能随 0.1.5-custom.36 提供。已放置模型的额外实体与灯具使用同一实时状态推送链路，控制面板和动效无需刷新页面即可更新。
