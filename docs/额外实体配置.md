# 额外实体选择与能力映射

入口：设备开发中心 → 打开项目 → 基础信息 → 额外关联实体。

先绑定主设备及其自身实体，再在同页搜索实体名称、实体 ID 或来源设备。可按类型筛选、仅看已选，直接勾选额外实体后点击「保存额外实体」。筛选不会清空选择；取消更改恢复上次保存。历史已选但当前不可用的实体仍保留，便于移除或等待恢复。页面只选择实体，不配置联动或动效。

保存后进入原有「能力与属性映射」：将额外实体映射到已有能力，或使用「新建能力并映射」。例如将 `device_tracker` 的 `state` 配置为「车辆位置」字符串状态能力，再到「3D 外观 → 部件动效」中选取这个能力。到家值需要使用跟踪器实际提供的原始状态，例如 `home`。

车辆模型默认显示时，可设置「车辆位置不等于 home → 显隐 → 隐藏」，条件结束后恢复原状。这样在家显示、离家隐藏。显隐、位移、颜色、发光、流光、扫光和数值映射均沿用原有动效逻辑，不增加独立规则系统。未知、不可用或 HA 离线遵循现有动效的恢复行为。

额外实体不会改写主设备绑定，也不会改变该实体在 HA 中的归属。取消关联已被能力使用的实体时，该能力映射会解除，能力定义与动效规则保留并提示重新绑定。主设备自身实体重新保存时保留额外关联；更换主设备后需重新核对额外选择与能力映射。实体注册表改名时同步更新选择和能力映射。

这些选择属于当前 HA 实例的绑定数据。便携设备包仍只携带能力和动效定义，不自动导入实体实例绑定。功能在本地 8101 验证，不代表已发布新的 HAOS 版本。
