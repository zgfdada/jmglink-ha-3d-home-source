# 当前版本说明

## 0.1.5-custom.32 - 2026-10-27

### 新增与优化

- 提供事件通知与 HA 主机整机资源控件样板，事件直接显示移动端通知日志；CPU、内存占用及已用/可用内存由绑定实体提供。
- 离线设备统计、待补充耗材拆分为独立控件，支持原有显示条件和统一时段主题；离线统计只保留右上角刷新入口，补齐设备图标并加大加粗 Low 等级。
- 3D 灯光按 HA 当前颜色模式解析真实色温、RGB、HS、XY 与白光通道，多灯按亮度混色，移除固定暖色覆盖。

### 修复与移除

- 修复离线统计刷新目标与结果等待；明确区分无变化、超时及失败。
- 移除旧在线模型页面、目录、预览、安装、发布接口和专用 Gitea 实现，准备重新设计。本地上传、已有模型文件、来源元数据及设备引用保留。
- 修复模型大图因列表缩略图占满渲染名额而空白的问题。

### 升级说明

- .31 标签未触发正式构建，未发布安装版本；本次直接发布 .32。

- 升级前备份数据目录，升级后强制刷新前端。现有户型、侧栏、控件和模型保留。
- 新安装仍只内置主页与天气。运维、事件等样板通过控件设计或导入使用，不强制加入现有布局。
- 本版本不包含旧在线目录；已安装模型继续使用本地资源。
- 本地验证：266 项自动测试、7 项发布检查、前端构建及浏览器模型预览通过。正式发布结果以 Release 的验证记录为准。

## 0.1.5-custom.30 - 2026-10-26

- 全新侧边栏开发中心：实体配置、页面设计、竖向楼层选择和可拖动导航。
- 编辑器提供高亮、换行、语法校验与格式化。
- 支持单控件、控件库、导航页、侧栏及完整实例迁移；导入前保留业务备份。
- 新增控件自动选中并定位，删除操作需要复核。
- 修复预览滚动、主题颜色、浮层交互；轮廓线默认固定 10%。
- 完整实例备份不含 HA/Hermes 连接凭据，恢复后重新连接并核对实体。外部 URL 资源仍需可访问。
- 升级前建议备份数据目录，升级后强制刷新前端。

发布验证：源码 CI #86 用时 4分31秒；正式发布 #87 用时 21分31秒；成功 Action 累计 26分02秒，从本轮 CI 开始到发布结束共 27分30秒。此前 .29 失败运行另计：CI #84 为 2分51秒，发布 #85 为 40分03秒；含中断与修复的总历时为 8小时06分21秒（03:02:02 至 11:08:23）。

## 0.1.5-custom.28 - 2026-10-23

### 修复

- 导航列表与收放按钮改为独立网格区域；根据侧栏实际高度压缩按钮、图标和间距，极小高度时列表独立滚动，避免横屏重叠。

- 手机竖屏的楼层栏收窄到 40px、收起侧栏收窄到 52px，并缩小栏间距；横屏和桌面宽度不变。

- 移除手机端侧栏 244px 固定高度，按可用区域上下拉伸，楼层栏与导航等高。
- 自动取景目标限制在轨道控制器允许的距离范围内，避免竖屏目标不可达导致持续回弹；手动触摸或鼠标操作立即取消自动取景。
- 保持默认俯视及水平完整旋转，手动倾斜后不回到俯视；侧栏收放不触发相机复位。

验证：252 项自动测试和前端构建通过；430×932 浏览器布局检查中两栏高度均为 836px。956×440 与 740×320 横屏下收放按钮与导航区域无交叠；正式镜像由 CI 构建验证，尚未更新 HAOS。


### 升级

- 保留现有户型和侧栏设计。新安装仍默认仅有主页与天气。
