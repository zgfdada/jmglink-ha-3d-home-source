# 数据备份与升级

## 更新前

- 在 3D Home 中导出项目 JSON。
- Home Assistant 用户额外制作 Add-on 备份。
- 独立 Docker 用户保留 `docker-runtime-source`。
- 妥善保管 Home Assistant Token 和网关密钥，不要公开分享。

## Add-on 更新

1. 查看版本更新说明，确认目标版本已发布。
2. 在 Home Assistant Add-on 商店执行检查更新。
3. 打开 Custom Add-on，确认新版本号后点击更新。
4. 更新结束后检查项目、实体连接和新增功能。

正常更新会保留相同 slug 下的 `/data`。不要通过卸载重装代替更新。

## 看不到更新

依次确认：

1. 目标版本高于当前安装版本。
2. Gitea 已存在同版本 Release 和多架构镜像。
3. HA 中仍保留本项目仓库地址。
4. HA 主机能够访问 Gitea 代码和镜像仓库。
