# JMGLink HA 3D Home Custom Wiki

这是 JMGLink HA 3D Home 的家居可视化应用，支持独立 Docker 和 Home Assistant Add-on 两种部署方式。

当前稳定版本：**v0.1.5-custom.33**。安装与升级只需拉取已发布镜像。

## 主要功能

- 设备按 Home Assistant 房间筛选。
- 柜类家具可编辑外轮廓、柜门面和数量，并可绑定水平基准面设置相对偏移。
- 连续多段墙体自动拉直。
- 修复 Home Assistant Ingress 项目 JSON 导出。
