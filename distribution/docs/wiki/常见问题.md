# 常见问题

## 官方版项目无法导出怎么办？

先制作包含官方 Add-on 的 Home Assistant 备份。当前版本已修复 Ingress 导出，但不要在没有备份时直接卸载官方版。

## 更新会删除项目吗？

相同 Add-on slug 的正常更新会保留 `/data`。卸载 Add-on 或删除独立 Docker 数据目录会造成数据丢失。
## 多终端语音提示来源校验失败

v20 及之前可能在 HA Ingress／反向代理改写 Host 后误拒绝正常终端。升级至 `0.1.5-custom.21` 并刷新页面，无需重建 Hermes 密钥或复制其他终端的 Cookie。配置保存在同一服务端，各终端仍需分别登录 HA、允许麦克风权限；完整说明见仓库的“语音助手配置”文档。

## Telegram 已回复，网页却先提示失败

升级到 `0.1.5-custom.22` 并强制刷新页面。v22 改用短提交和进度查询，不让一条 HTTP 连接等待完整模型执行；提交响应或进度短暂断线时只读取原任务，不重发指令。请先核对 TG 和设备实际状态，不要因为网页提示而重复操作。进程重启、执行错误和整体等待超时仍会明确提示；具体说明见仓库“语音助手配置”。


## 设备开发中心或模型预览异常

.37 加入场景局部隔离和恢复、旧前端模块失效恢复以及预览资源释放。升级后先强制刷新；若显卡上下文创建失败，使用场景内恢复入口，避免同时打开过多 3D 页面。已保存的户型、模型和规则保留。

## 额外传感器状态与动效不更新

升级到 .37 并强制刷新以载入新前端。确认额外实体已保存且能力映射正确，规则条件使用实体原始值（例如 `not_home`），不是显示标签“离家”。运行后状态走实时推送，无需反复刷新。未知、不可用或 HA 断线按规则原有结束行为处理。
