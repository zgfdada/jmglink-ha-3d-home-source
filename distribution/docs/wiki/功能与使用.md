# 功能与使用

## 本地模型资源库

从 .31 起已移除旧在线模型页面和接口，在线部分准备重新设计。本地上传、预览、配置、收藏和应用到设备继续可用，此前已安装的模型及其素材、引用关系保留。

## 按房间筛选设备

进入编辑页的设备库，在设备类型筛选下面选择 Home Assistant 房间。房间、设备类型和搜索词可以组合使用。独立 Docker 必须先连接 Home Assistant，界面才会显示真实房间。

## 柜类家具离地高度

衣柜、橱柜、电视柜、书架、餐边柜、鞋柜和床头柜可以在“尺寸与位置”中设置离地高度。单位为米，范围 0–12 m，步进 0.05 m。保存后编辑预览和全屋 3D 会同步抬高。

## 多段墙体拉直

切换到“选择”，按住 Shift 或 Ctrl 选择至少两段首尾相连的开放墙链，再点击“自动拉直选中墙体”。系统会按整条墙链校正为水平、垂直或斜直线，同时处理连接墙、门窗和房间面积。结果不满意可使用 Ctrl+Z。

## 项目导入导出

当前版本已经修复官方 0.1.5 在 Home Assistant Ingress 中导出 HTTP 415。迁移前后都应导出项目 JSON 作为独立备份。

## 摄像头与控件（.33）

支持枪型、球型单摄／双摄及桌面摄像头。双摄在属性中绑定第二路 camera 实体，控制面板提供双缩略图，播放打开大浮层，居中标签切换画面。支持 HA 实时流、快照回退、Frigate／ONVIF 云台以及外部访问链接。枪型、球型默认天花板参考并限制穿顶。内置面板控件精简为 12 项，既有面板快照与自定义控件保留。

## 部件动效与额外实体（.37）

设备开发中心第四项“动效资源库”同页展示 JavaScript／GLSL 代码和实时效果，可校验、编辑和保存。设备项目在“3D 外观 → 部件动效”中选择中文部件、能力、条件和动效，验证模拟后保存。部件需要在建模时分离并使用稳定节点；规则保存独立快照，修改资源不会无提示覆盖已有规则。

“基础信息 → 额外关联实体”直接搜索和选择外部传感器、跟踪器等实体，也可不绑定自身 HA 设备。保存后在“能力与属性映射”配置能力，再供原有动效和控制面板使用。车辆离家隐藏可匹配原始 `not_home`，条件结束恢复；额外实体与灯具共用实时状态推送。实例绑定不会随便携设备包迁移。

编辑门窗时，门磁绑定使用一个可搜索下拉框，兼容 sensor 和 binary_sensor；手机横竖屏隐藏主页开发入口。详情参阅[版本说明](../../RELEASE_NOTES.md)。

## .38 模型与窗帘编辑

窗帘支持自由绘制连续轨道、节点调整和自动应用，区分遮光帘与纱帘。模型部件可重复点击反选、Ctrl 多选，多部件共用旋转轴心；可拖动中心，角度滑块直接设置目标角度。新增规则从空部件选择开始，保存后退出规则编辑。预览最多同时占用两个资源槽，离屏和关闭时回收。

## .39 日月光与室内漫游

主页环境光面板可调整户型北向、日光、月光和阴影强度；方向实时预览，结束调整保存。月光需要 Lunar Phase 的位置与照亮比例数据，未配置时面板提供提示。右侧 HA 离线提示不再将短暂断线显示为实体删除。

页面工具选择“室内漫游”，点击房间空地进入。电脑 WASD／方向键移动、鼠标拖动环顾；手机使用摇杆和拖动。Esc 或退出按钮恢复原视角；第一版使用简化碰撞，仅当前楼层。
