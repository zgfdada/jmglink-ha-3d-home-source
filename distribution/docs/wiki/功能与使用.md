# 功能与使用

## 本地模型资源库

从 .31 起已移除旧在线模型页面和接口，在线部分准备重新设计。本地上传、预览、配置、收藏和应用到设备继续可用，此前已安装的模型及其素材、引用关系保留。

## 按房间筛选设备

进入编辑页的设备库，在设备类型筛选下面选择 Home Assistant 房间。房间、设备类型和搜索词可以组合使用。独立 Docker 必须先连接 Home Assistant，界面才会显示真实房间。

## 柜类家具离地高度

衣柜、橱柜、电视柜、书架、餐边柜、鞋柜和床头柜可以在“尺寸与位置”中设置离地高度。单位为米，范围 0–12 m，步进 0.05 m。保存后编辑预览和全屋 3D 会同步抬高。

## 多段墙体拉直

切换到“选择”，按住 Shift 或 Ctrl 选择至少两段首尾相连的开放墙链，再点击“自动拉直选中墙体”。系统会按整条墙链校正为水平、垂直或斜直线，同时处理连接墙、门窗和房间面积。结果不满意可使用 Ctrl+Z。

## 项目导入导出

当前版本已经修复官方 0.1.5 在 Home Assistant Ingress 中导出 HTTP 415。迁移前后都应导出项目 JSON 作为独立备份。
