# 当前版本说明

## 0.1.5-custom.27 - 2026-10-23

### 修复

- 图片代理保留 Supervisor 的 `/core` 前缀，修复 HAOS 中海报接口返回 403。
- 宿主页使用当前 Ingress 会话读取已绑定实体图片，校验类型及大小后以 data URL 传入隔离控件；不传递 Cookie 或 HA 凭据，修复隔离 iframe 直接加载图片缺少会话的问题。
- 收起后的导航使用完整内部宽度，导航项及底部收放按钮共用中心线。

### 变更

- 初始布局仅包含主页导航和天气控件；能耗、运维、音乐保留为可选代码示例，不再默认添加。
- 移除启动时自动注入能耗和覆盖已保存控件代码的迁移，保留用户自定义布局。
- 同步可下载 Skill 的默认示例及说明。

验证：251 项测试及前端生产构建通过；HAOS ttyd 实测图片代理 200/JPEG，真实 Ingress 内海报 naturalWidth=500，收起按钮水平居中误差 0px。已在用户 HAOS 的 .26 容器应用带回滚备份的热修复；正式镜像由发布 CI 构建并验证。


### 升级

- 更新 HA App 至本版本或重新拉取 Docker latest 镜像，升级后 Ctrl+F5 刷新。
- 新安装默认仅有主页和天气；已保存的自定义布局保留，不自动删除已有页面和控件。
