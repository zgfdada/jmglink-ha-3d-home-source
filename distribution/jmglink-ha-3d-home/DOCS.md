# JMGLink HA 3D Home Custom

这是 Home Assistant 的 3D 家居可视化应用，保留 Ingress、Supervisor API、项目管理和 3D 控制能力。

当前稳定 Add-on 版本为 `0.1.5-custom.32`，具体变化请查看 [版本更新日志](RELEASE_NOTES.md)。

## 当前版本

支持 HA / Hermes 语音助手、多终端、澄清选择与回复播报；短请求恢复原任务结果，不自动重发设备指令。右键麦克风打开配置。安装升级直接拉取镜像。

## 增强功能

- 编辑页设备库支持按 Home Assistant Area 房间筛选，并可与设备类型和关键词组合使用。
- 柜体统一为一种可编辑家具：基础柜体的上、下、左、右 4 条闭合外轮廓边均可直接选择，拖动端点或中央整边移动手柄可形成 L、U 或任意异型轮廓，也可拆分及合并共线边；保留原有柜体样式，可指定任意边为柜门面、配置柜门数量，编辑时提供平行/垂直吸附高亮；二维占地与三维实体使用同一闭合轮廓。
- 家具可绑定楼层地面或其他家具、设备的顶面或底面，并设置相对偏移；不再重复提供“离地高度”输入。
- 编辑页支持将连续的多段墙体自动校正为水平、垂直或斜向直线，并同步更新相连墙体、门窗位置和房间边界。
- 创建墙体、放置设备以及拖动设备、整面墙或墙体端点时，会针对其他设备中心和墙体端点/中点显示水平、垂直对齐辅助线并自动吸附。
- 多选连续且共线的墙体后可合并为一段，原门窗位置及房间拓扑会自动更新。
- 单选墙体后可通过滑块、精确距离或快捷比例预览分割点并拆成两段，门窗归属与房间拓扑会自动更新。
- 虚拟墙参与 2D 房间规划和面积计算，但不会在 3D 场景中显示；旧版透明边界数据会自动兼容。
- 多选共线墙体后可通过整条墙链的首尾端点和整体平移手柄联动调整全部分段。
- 多选至少三个设备后可排列到同一直线；已经共线时可保持两端位置并等距排放。

## 安装

1. 进入 Home Assistant 的 **设置 → 加载项 → 加载项商店**。
2. 打开右上角的仓库管理。
3. 添加以下仓库地址：

   ```text
   https://gitea.700117.xyz:16666/zgf/jmglink-ha-3d-home-custom
   ```

4. 刷新加载项商店并选择 **JMGLink HA 3D Home Custom**。
5. 点击安装。Supervisor 会从 Gitea 镜像仓库下载与 HA 主机架构匹配的预构建增强版。
6. 启动后开启“在侧边栏显示”。


## 在线 3D 模型库

Add-on 默认以匿名只读方式连接公开模型库，不需要 Gitea 账号或 Token。在设备开发中心打开“在线模型库”即可浏览、预览和下载模型。当前公开服务只提供 IPv6 入口；如果加载失败，请先确认 Home Assistant 主机具有可用的 IPv6 DNS 和出站连接。匿名上传暂未开放。

## 从原版迁移项目

原版与增强版使用不同的 Add-on slug，可以并存，但各自拥有独立的 `/data` 目录。推荐通过项目 JSON 迁移：

1. 在原版中打开项目管理并导出项目 JSON。
2. 安装并启动增强版。
3. 在增强版项目管理中导入 JSON。
4. 检查楼层、房间、设备和家具后保存。
5. 直接点击柜体外轮廓的任意一边进行选择：可将当前边设为柜门面；拖动蓝色端点调整相邻两边，拖动中央十字移动整条边并保持轮廓闭合，接近平行或垂直关系时自动吸附并高亮；需要增加转折时拆分所选边，需要整理直线时使用“合并共线边”。

旧项目没有 `elevation` 字段时会自动按 `0 m` 加载。增强版导出的 JSON 如果再导回官方原版，项目仍能显示，但官方原版会删除 `elevation`，柜类家具将回到地面。

确认迁移成功前不要卸载原版，并保留导出的项目 JSON。

## 使用

1. 从侧边栏进入 **3D Home Custom**。
2. 打开户型编辑器。
3. 在设备库的类型按钮下方选择 HA 房间，筛选待放置设备。
4. 选择柜类家具，在“水平基准面”中选择绑定面并设置相对偏移。
5. 需要拉直墙体时，切换到“选择”，按住 `Shift` 或 `Ctrl` 逐段选择同一条连续墙链，然后在右侧点击 **自动拉直选中墙体**。
6. 需要分段时只选择一段墙体，在右侧 **线段分段** 中调整十字预览标记，然后点击 **在标记处分为两段**。
7. 只用于划分空间的边界可在“墙体类型”中设为 **虚拟墙**。
8. 多选共线墙体后，直接拖动整条墙链的平移手柄或首尾端点；各分段会保持连接。
9. 多选至少三个设备，在右侧 **设备排列** 中先成线；已经共线时可执行等距排放。
10. 检查房间边界和门窗位置；结果不合适时按 `Ctrl+Z` 撤销。
11. 保存项目并切回全屋视图检查 3D 位置。

Add-on 模式使用 Supervisor 提供的 `SUPERVISOR_TOKEN` 连接当前 Home Assistant，不需要手动填写 HA 地址或长期访问令牌。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `log_level` | `info` | 排查问题时可改为 `debug` |
| `external_access` | `false` | 常规 Ingress 使用保持关闭 |
| `node_max_old_space_mb` | `256` | Node.js V8 old-space 上限，允许 `128–512 MiB`；约 2 GiB 内存的 HAOS 主机建议保持默认值 |
| `nice_level` | `10` | 后台进程 nice 值，允许 `0–19`；数值越大 CPU 优先级越低 |
| `resource_log_interval_minutes` | `5` | 资源统计日志间隔，允许 `0–60` 分钟；设为 `0` 关闭 |

修改配置后保存并重启 Add-on。

资源日志以 `Runtime resource usage` 标识输出 RSS、V8 堆、外部缓冲区、CPU、浏览器 WebSocket 客户端、HA 待处理命令及历史缓存写盘队列。日志只包含计数和内存用量，不包含令牌、项目内容或实体属性。

## 数据和备份

项目、备份和素材数据保存在 Add-on 的持久化目录中，并由 Home Assistant 备份机制管理。进行大规模户型调整或迁移前，仍建议从项目设置页面执行“导出完整备份”。该 JSON 会同时包含当前户型、自定义设备模板与绑定、3D 模型配置和本地模型文件、控制面板及内置模板隐藏记录；导入时会一起恢复。旧版项目 JSON 仍可导入，但不会覆盖设备平台数据。

## 零基础更新教程

本应用的 slug 固定为 `jmglink_ha_3d_home_custom`。正常更新会保留同一 slug 的 `/data`，因此不需要重新导入项目。

1. 更新前从 3D Home 项目设置导出一份完整备份 JSON。
2. 进入 **设置 → 加载项/应用 → 加载项商店/安装应用**。
3. 打开右上角菜单，执行 **检查更新/重新加载**。
4. 等待仓库刷新后，打开 **JMGLink HA 3D Home Custom**。
5. 确认页面显示比当前安装版本更高的新版本号，然后点击更新。
6. 等待 HA 下载预构建镜像并重启 Add-on，通常只需几分钟。
7. 更新结束后确认 Add-on 已启动，从侧边栏打开页面并使用 `Ctrl+F5` 强制刷新。
8. 检查项目仍在、HA 状态已连接，并验证新功能。

不要通过卸载后重装来代替更新；卸载会删除 Add-on 数据。如果 HA 没有显示更新按钮，请依次检查：

- HA 仓库列表中是否仍有本项目 Gitea 地址。
- HA 主机是否能访问 Gitea 代码与镜像仓库。


## 常见问题

### 商店里仍显示官方版本

确认添加的是本增强版 Gitea 地址，并选择名称带 `Custom` 的 Add-on。原版和增强版会分别显示。

### 镜像下载失败

检查 HA 主机能否访问镜像仓库，以及磁盘空间和网络连接。

### 页面没有房间筛选

确认当前打开的是 **JMGLink HA 3D Home Custom**，版本为 `0.1.5-custom.32`。升级后使用 `Ctrl+F5` 刷新前端资源。

### 看不到实体或无法控制

确认 Add-on 配置保留 `homeassistant_api: true`，并检查日志中的 Supervisor 连接和 Home Assistant WebSocket 错误。
