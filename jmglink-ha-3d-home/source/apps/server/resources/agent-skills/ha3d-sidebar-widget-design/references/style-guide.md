# 当前风格规范

- 主页没有 HOME OVERVIEW/3D智家标题区。内容栏两侧各 8px，控件间距 10px。导航在内容右侧的 54px 轨道内居中，收放按钮独立固定在底部。
- 控件宽度 100%，自然高度。不要写 height:100%、固定高度截断、控件级滚动条或为了撑高而加空白。宿主 ResizeObserver 自动报告 #view 内容高度，允许侧栏整体滚动。
- 背景只由宿主 `.sb-widget-surface` 绘制：白天 `rgba(57,94,116,.72)`，浅字 `#f5f9ff`；黄昏/夜间 `rgba(223,227,232,.80)`，深字 `#14283f`。圆角 17px，细边框 `#ffffff55`。控件 html/body/#view 保持透明，禁止叠加 backdrop-filter、渐变底或内阴影形成边缘色带。
- 使用 `var(--widget-text)`、`var(--widget-muted)`、`var(--widget-line)`；不要在代码中锁死字体颜色或按电脑时间猜主题。宿主根据当地太阳高度及手动预览下发主题。
- 标题 14–15px，次要说明约 11px；留白参考控件代码。天气图标、数值、单位作为同一 Flex 组居中，单位与数值间距 7px，基线对齐。条件、湿度、风速居中。
- 日期时间位于天气标题右侧；使用 data-clock=date/weekday/time，宿主每秒更新。使用实体提供的真实温度、状态、预报，不伪造数据。
- 能耗名称优先用户配置，其次属性 title/customer_name/user_name，再次 friendly_name/name。保留多户切换；统计和缴费详情打开顶层场景浮层，保留当前户，不挤在小卡内。
- 主页、控件预览和页面设计共用相同渲染器。主题切换只更新样式与数据，交互 iframe 不因实体广播重载。
- 黄昏场景用暖灰橙背景，白天蓝灰、夜间深蓝；本控件不能操纵全局场景或真实灯光。
- 开发中心编辑区白底深字，卡片预览保留实际主题。
