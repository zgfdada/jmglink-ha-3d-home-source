# 更新日志


## 0.1.5-custom.43 - 2026-11-07

### 新增

- 3D 资源库新增浅色投影仪、电动幕布、左右声道音响与低音炮，支持家居摆放和设备模型绑定；设备可按 HA 开关状态显示投影柔光、幕布收放及幕面光泽。
- 侧栏提供 Home3D MCP 使用 Skill v1.0.0 下载，覆盖连接、权限、视觉方案确认、应用层配置、资源登记、设备动画、Node-RED 与多视角验收。

### 优化

- MCP 的 HA 实体范围支持显式 `*`，覆盖全部当前及后续实体；保留具体服务能力、版本和幂等校验，不自动扩大已有实例的授权范围。
- 完整 Node-RED tab 权限下，可通过 `nodered.flows.get` 的 `tabId: "*"` 读取流程页列表，再按具体 tab 读取节点。
- 情景页去除大块填充底色时保留透明毛玻璃；小号控件支持主题底色、整卡点击和两列自适应宽度。Node-RED 按钮作为情景入口时需显式纳入实体绑定，未触发的 button 状态 unknown 不代表离线。

### 修复

- 透明度调整仅作用于墙体；忽略旧预设中的家具、地面与背景透明度。HA 离线提示保持模型原有透明材质属性，不再将车身、家具和设备整体淡化。
- 影院设备使用专用效果，避免通用运行流光给投影光束生成大范围发光边框。

### 升级与范围

- 保留原数据、素材、浏览器偏好与部署路径；升级后强制刷新浏览器。
- 新安装可从资源库选择影院模型。HA 实体、资源实例、设备绑定及观影 Node-RED 流程按各自项目配置，不预置个人户型或真实家庭实体。
- 本版本发布验证使用隔离数据，不调用真实 HA／Node-RED 服务。

## 0.1.5-custom.42 - 2026-11-07

### 新增

- 独立 MCP HTTP 服务与共用权限管理，支持3DHome项目／侧栏计划、应用与恢复，以及明确授权范围内的HA／Node-RED操作；Node-RED支持Basic和Bearer，凭据加密且不回显。
- MCP浮窗增加红绿状态灯、连接排查引导、自定义共享连接地址和恢复默认；点击外部或Esc收起，修复点击穿透。Docker监听和映射端口可配置。
- 风格编辑集中至右侧栏；三种内置模板不可覆盖，自定义风格支持新建、修改、另存为、删除并兼容已有浏览器预设。

### 优化

- 主页侧栏四边停靠与位置记忆、可搜索实体复选卡片、手动环境光记忆和实时风格预览。
- 单灯散射角及恢复跟随类型位于灯具控制面板，环境光仅维护灯型默认值。
- MCP采用免密共用权限、校验后免人工批准应用；保留同源、资源范围、版本及幂等校验，不改变已有HA／Node-RED授权。

### 修复

- MCP管理页API使用相对路径，保留Home Assistant Ingress子路径；App和Docker共用同一实现。

- 恢复手动俯仰；修复旋转后漫游模型与碰撞坐标错位，柜体和沙发按实际轮廓碰撞。
- 日月光与房屋共用旋转根，保持相对入射方向；修复侧栏总览备份引用及实时订阅范围遗漏。

### 升级与部署

- 保留data、assets、App slug及浏览器偏好，升级后强制刷新。MCP私有目录单独备份，不包含于普通实例导出。
- MCP随App／Docker镜像一同安装和升级，均需显式启用。App配置页开启mcp_enabled，网络页映射8102/tcp，并将mcp_public_port设为实际宿主端口；保存URL不改变监听或映射。
- 免密MCP仅供可信网络和客户端；Node-RED可信代码不是安全沙箱。真实上游写入不属于发布自动测试范围。

## 0.1.5-custom.40 - 2026-11-05

### 新增

- 环境光面板支持墙体透明度（0–100%，默认45%）与8类灯具散射角（1°–160°）；每盏灯可独立覆盖并恢复跟随类型，设置仅影响三维展示。
- 可见光束使用带灯口截面的截锥，按灯型匹配出光口，沿距离逐渐变淡并在末端平滑消失。
- 多楼层 ALL 总览支持按户型尺度展开、暖白楼板灯带和柔光底座；星空与户型旋转同步。

### 优化

- 墙体采用柔和乳白透明显示，0%透明度恢复原材质；内置柜体颜色调浅，导入模型保留原配色。
- 主页固定俯角，左键旋转、右键整体平移、滚轮缩放，拖拽松手即停。默认自动旋转，交互及控件焦点暂停；连续空闲8秒后归回户型轴心并恢复旋转，保留观察角度和缩放。

### 修复

- 点光／聚光在照明和高光计算前统一检查实体墙光路，避免隔墙卫浴表面异常反光；省电档关闭阴影贴图时仍执行墙体遮挡，真实门窗洞口可通光。
- 设备运行状态不再以大范围点光晕染色周围场景。
- 自定义设备发布发生网关错误或连接中断时，保留明确的内存排查提示，说明 Node.js 堆上限、容器内存限制、重启与发布版本核对步骤。

### 升级说明

- 升级前备份完整实例及数据／素材目录，保留原挂载路径和slug；升级后Ctrl+F5刷新。墙体、星光与散射角偏好保存在当前浏览器。
- 支持HAOS App及Docker，AMD64／ARM64多架构。发布包不携带个人户型、模型或测试实体；推广站的浏览器内演示与真实HA隔离。

## 0.1.5-custom.39 - 2026-11-03

### 新增

- 第一人称室内漫游：点击落脚点，电脑键盘移动、鼠标环顾，手机使用摇杆与拖动；支持简化碰撞及门洞通行，退出恢复原视角。
- 日光按 HA 太阳方位、高度和户型北向实时计算；接入 Lunar Phase 月亮位置与照亮比例，夜间提供月光。环境光面板支持北向、日光／月光及阴影强度热调整。
- 右侧常驻 HA 离线／同步提示；缺少月光集成或数据时提供具体原因与配置入口。

### 修复与安全

- 修复墙体漏光、异常投影与隐藏遮光屋顶挡住室内视图；屋顶遮光可选。
- 加强项目保存串行化、版本冲突及原子写入保护，补齐楼层侧栏实时订阅和恢复后的状态同步。
- 模型 Worker 解码支持终止、超时及资源预算；更新依赖和访问来源校验，独立部署支持访问密码。

### 发布与升级

- 源码、安装库迁至 GitHub，镜像迁至 `ghcr.io/zgfdada/jmglink-ha-3d-home-custom`，提供 AMD64／ARM64 多架构及 HAOS 更新说明。
- 升级前备份 App 或数据目录；保留原 slug 与数据卷，升级后强制刷新。旧 Gitea 安装源用户需添加 README 中的 GitHub 安装仓库。
- 月光为可选功能：需要 Lunar Phase 提供月亮方向、高度及照亮比例；缺失时提示配置，不影响其他设备及日光。
- 漫游第一版仅当前楼层，采用简化碰撞，不代替精确物理模拟；不携带个人模型、户型、教程愿景或测试实体数据。

## 0.1.5-custom.38 - 2026-11-02

### 新增与优化

- 窗帘可自由绘制连续轨道，支持直线、L 形、U 形、节点编辑和自动应用；区分遮光帘与纱帘，取消整体缩放。
- 模型旋转规则支持共同轴心、多部件刚性旋转、拖动旋转中心、固定屏幕大小的 XYZ 标注；角度滑块直接配置目标角度。
- 模型点击支持反选及 Ctrl 多选，保存规则后退出编辑；新增规则不再自动选中部件。
- 模型预览限制同时活跃资源为两个，完善离屏、卸载、异步失败与图像资源回收，降低资源压力。
- 主页控制面板改为点击外部关闭的浮层，设备绑定支持搜索替换，跟踪器显示于顶部。

### 修复

- 修复旋转时偏移部件分离、窗帘参数编辑阻挡切换设备的问题。
- 保存失败提示具体原因与实体名称；前台气泡限频淡出，后台仍按约一秒自动重试，增加超时和分阶段诊断日志。

### 升级说明

升级前备份数据目录，升级后强制刷新浏览器。保留已保存户型、设备和规则；多部件角度规则现在共用首个顶层部件参考轴心，请复核原规则。新规则需要手动选择部件才能保存。
正式安装包不携带教程愿景、个人模型、户型或测试实体数据。HAOS 更新页提供本版本说明。

## 0.1.5-custom.37 - 2026-10-31

构建补充：.36 候选在 ARM64 模拟环境触发测试的过短期限，未完成正式交付。此版本让通用 JS 测试／打包原生执行，检查生产依赖不含平台绑定及原生扩展，并增加目标 ARM64 运行镜像验收；业务 Worker 的运行期限保持不变。

本次最终版本额外补齐删除车辆模型／项目后的主页定位订阅；.35 为此前候选，最终以 .36 为准。

.34 因发布检查仍使用旧入口脚本体积断言，未完成正式交付；本次修正为校验入口、依赖模块和发布清单哈希，并验证正式动效 Worker。已有 .34 标签保留，使用新版本 .35 交付。

### 新增

- 自定义模型支持中文部件树、部件选择和状态／数值驱动规则，提供位移、角度、持续旋转、缩放、显隐、颜色、发光、路径流光和表面扫光；可模拟预览、调整优先级、过渡和结束行为。
- 设备开发中心新增动效资源库，以代码与实时效果同页维护九类动效，支持 JavaScript 运动算法和扫光 GLSL、校验、复制、自定义资源及备份迁移。
- 基础信息直接搜索并选择额外关联实体，支持没有自身 HA 设备、仅关联传感器／定位跟踪器的独立模型；后续复用原有能力映射与部件动效配置。

### 修复

- 主页在家标签独立订阅 person／device_tracker，删除资源库模型或项目后仍实时更新定位，不依赖车辆绑定存在。

- 修复额外实体实时状态被过滤、刷新页面后才更新的问题；控制面板和动效共同使用实时数据，状态选择展示中文与 HA 原始值。
- 修复开发中心打开／退出、旧模块失效及 WebGL 创建失败导致的整页异常；场景局部恢复并释放后台渲染资源，补齐不含敏感数据的异常摘要。
- 修复部分模型缩略图、预览空白及卸载过程错误，控制并释放预览渲染资源。
- 内置与自定义模型按实际表面响应点击，光束、气流、流光、选中框不再扩大命中范围；修复灯具矩形选中光影。
- 门磁绑定使用单个搜索下拉框，支持 sensor／binary_sensor、长名称完整显示及中文开合状态，移除 3D 门扇悬空线框。
- 扫光采用通用名称，规则列表可直接删除规则；手机横屏、竖屏隐藏“开发与编辑”入口。

### 升级

- 升级前备份数据目录，升级后强制刷新浏览器。保留户型、设备、侧栏、模型和既有面板快照。
- 动效条件使用 HA 原始状态，例如跟踪器 `home`／`not_home`；中文标签仅用于展示。
- 动效资源编辑后需显式保存到规则；旧规则保留独立快照。额外实体不改写 HA 实体归属，便携设备包不携带实例实体绑定。
- 正式镜像和安装快照继续排除本地教程、愿景演示、个人户型、测试传感器及演示数据包。HAOS 更新页提供本版本 CHANGELOG。
