# 当前版本说明

## 0.1.5-custom.26 - 2026-10-23

### 新增

- 玻璃侧栏、彩色导航和独立收放；提供天气、家庭能耗、运维、音乐及房间控制代码样板。
- 侧栏开发中心支持 HTML/CSS/JS 编辑、实体搜索多选、动作配置、预览及独立草稿/发布。
- 通用 HA 状态订阅与服务转发，按控件声明、保存版本和绑定实体校验；新增控件无需后端专用业务代码。
- 按真实楼层生成左侧楼层选择栏，与侧栏等高；开发中心按楼层设计，原 F1 布局保留，新增楼层从空白开始。
- 可下载控件设计 Skill、接口说明和房间样板。

### 优化

- 天气实时时钟与预报、能耗多账户及月度/年度浮层；音乐复用现有卡片并支持展开交互。
- 房间提供灯光总控、智能模式、左右对开窗帘及空调能力选项；窗帘从当前进度模拟缓慢动画。
- 统一白天、黄昏、夜晚的侧栏与设备面板配色；侧栏保留滚动并隐藏滚动条。
- 默认使用与平面设计方向一致的俯视图，保留用户旋转和缩放。

### 修复

- 楼层栏和侧栏外壳统一采用已确认的楼层导航偏亮透光材质，共用背景、边框、阴影和模糊参数，消除黄昏和夜间的不同叠色。

- 修复侧栏和设备面板打开时相机重置、俯视旋转地基翻面及方向偏差。
- 修复歌曲搜索与实时歌词跟随、能耗状态更新重置当前账户和图表。
- 修复多楼层项目旧楼层导航重复渲染，文字出现在新侧栏背后的问题。
- 按楼层隔离控件草稿、发布与服务动作，防止其他楼层误用 F1 实体。

本地 Docker 生产构建、247 项测试及 Skill 校验通过。运行配置和 HA 凭据不会随版本发布。

### 升级

- HA App：更新仓库后升级到本版本；Docker：重新拉取 latest 并重建容器。
- 升级前备份持久化数据；升级后使用 Ctrl+F5 刷新前端。
- 保留现有项目及 F1 草稿和发布布局；新楼层需在开发中心选择对应楼层后设计并发布。
